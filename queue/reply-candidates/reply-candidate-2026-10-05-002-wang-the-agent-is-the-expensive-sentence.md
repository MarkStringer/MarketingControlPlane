The ladder is right, and it's worth saying what it actually is. Every rung up is a bigger stake, so you're describing a staged bet.

That changes how you climb it. The next rung shouldn't be unlocked because the architecture looks more impressive. It should be unlocked because the cheaper rung demonstrably failed at something you wrote down in advance.

"Let's build an agent" is expensive because it skips that. It picks the biggest bet before anyone has found out whether the smallest one pays.

Deliver the possible, not the fantasy. Start with the version that could prove you wrong, cheaply, and let its failures tell you what the next version needs.
