Agreed on the symptom, but the cause isn't data hygiene.

Teams don't accumulate dashboards because they forgot to be disciplined. They accumulate them because a dashboard is somewhere to leave a decision so that nobody has to be the one who made it. If the number turns out wrong, the number takes the hit. If a person makes the call, the person does.

That's why "we need more data" survives every attempt to trim it. It isn't really a request for insight. It's a request for cover.

You can't fix that with a tighter set of metrics, because the tighter set still can't do the one thing the room is avoiding, which is take a view and own it. Point of view is worth 80 IQ points. No dashboard has ever had one.

Learning fast and deciding smart both need someone willing to be wrong in public first. Give them that and the data problem mostly disappears.
