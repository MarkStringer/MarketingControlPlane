The "paid following up machine" is a real archetype. But the diagnosis is wrong.

PMs become status-chasers when the project has no honest definition of done. If nobody agrees on what success looks like, the only remaining task is to find out whether the thing nobody defined is happening on schedule.

Status-chasing is what project management looks like when the project is a fog. The PM didn't choose it. The project created it.

Fix the definition first. The following-up tends to resolve itself.
